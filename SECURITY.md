# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (the "Report a vulnerability" button
under the Security tab of this repository). Do not open a public issue with the details.

Include a description, steps to reproduce and the affected version.

## What to expect

- Acknowledgement within 3 business days.
- Initial assessment within 10 business days.
- Credit for the finding if you want it.

Only the latest version receives security fixes.
