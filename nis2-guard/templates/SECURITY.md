# Security policy

## How to report a vulnerability

Email **security@your-domain.example** (replace with a real mailbox). If you can, encrypt
the message with the PGP key published in this repository.
Please do not open a public issue with the details.

Include a description, steps to reproduce and the affected version.

## What you can expect

- Acknowledgement within 3 business days.
- Initial assessment within 10 business days.
- We will let you know before publishing the fix and, if you wish, credit you for the finding.

## Supported versions

| Version  | Security support |
|----------|------------------|
| latest   | Yes              |
| previous | Critical fixes only |

## Coordinated disclosure

We ask for a reasonable period (90 days as a reference) before the issue is made public.
